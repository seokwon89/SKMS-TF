# 연구계획서 v0.1 — 글로벌 기업의 Creed 기반 경영철학 도입: 목적·결과·교훈

- 작성일: 2026-09-30
- 상태: 초안 (연구 설계 단계, 사례 사실관계 미검증)

## 1. 연구 주제

**국문**: 선언에서 작동으로 — 글로벌 기업의 Creed 기반 경영철학 도입 목적, 결과, 그리고 성패를 가르는 조건에 관한 비교 사례연구

**영문**: From Declaration to Operation: A Comparative Case Study of Creed-Based Management Philosophy in Global Firms — Purposes, Outcomes, and Conditions for Success

**한 줄 요약**: 기업이 가치를 "적어 두는 것"과 가치가 "의사결정을 실제로 바꾸는 것" 사이의 간극이 어디서, 왜 생기는지를 사례 비교로 규명한다.

---

## 2. 배경과 문제의식

1. 대부분의 대기업은 미션·비전·핵심가치를 갖고 있다. 그러나 가치 선언문 보유 자체는 흔하므로 **"보유 여부"는 성과를 설명하지 못할 가능성이 높다.** (가설 — 관련 실증연구는 §6에서 확인)
2. 일부 기업은 가치를 단순 슬로건이 아니라 **"Creed(신조)"** — 이해관계자에 대한 책임과 우선순위를 명문화하고, 이를 의사결정·평가·위기 대응의 기준으로 쓰는 문서 — 로 운영해 왔다고 알려져 있다.
3. 동시에 화려한 가치 선언을 갖고도 대형 윤리 스캔들을 겪은 기업 사례도 존재한다.
4. 따라서 핵심 질문은 "Creed가 좋은가?"가 아니라 **"어떤 목적으로, 어떻게 설계·운영했을 때, 어떤 결과가 나왔고, 무엇이 차이를 만들었는가?"** 이다.

## 3. 핵심 개념 정의 (조작적 정의)

연구 품질을 좌우하는 첫 관문. "Creed"라는 단어를 쓴 기업만 보면 표본이 지나치게 좁아지고, 모든 가치 선언을 포함하면 개념이 흐려진다.

### 3.1 인접 개념 구분

| 개념 | 핵심 질문 | 성격 | 예시 형태 |
|---|---|---|---|
| Mission / Purpose | 우리는 왜 존재하는가 | 존재 이유 | 한 문장 |
| Vision | 어디로 가는가 | 미래 상태 | 목표 서술 |
| Core Values | 무엇을 중시하는가 | 가치 목록 | 3~7개 키워드 |
| Code of Conduct | 무엇을 하면 안 되는가 | 규범·준법 | 규정집 |
| **Creed / 경영철학** | **누구에게 어떤 순서로 책임지며, 충돌 시 무엇을 우선하는가** | **판단 기준 + 약속** | 서술형 선언문 |

### 3.2 본 연구의 Creed 판정 기준 (4개 중 3개 이상 충족 시 포함)

- **C1 명문화**: 공식 문서로 존재하고 전사에 공개됨
- **C2 우선순위·책임 구조**: 이해관계자 또는 가치 간 우선순위, 충돌 시 판단 원칙을 담음
- **C3 제도 연결**: 채용·평가·승진·교육·의사결정 절차 중 하나 이상에 공식 연결
- **C4 지속성·개정 절차**: 일정 기간 이상 유지되었거나, 개정 절차·주기가 존재

> 명칭("Creed", "Way", "Philosophy", "Principles" 등)은 판정 기준이 아니다. 기능으로 판정한다.

## 4. 연구 질문 (RQ)

| RQ | 질문 | 대응 산출물 |
|---|---|---|
| **RQ1 목적** | 기업은 왜 Creed를 도입·재정립했는가? (창업자 철학 계승, 위기 대응, M&A 통합, 글로벌 확장, 턴어라운드, 신뢰 회복 등) | 도입 동기 유형 분류 |
| **RQ2 설계** | Creed의 내용·구조는 어떻게 설계되었는가? (이해관계자 우선순위, 추상도, 길이, 참여형/하향식 작성) | 설계 특성 비교표 |
| **RQ3 내재화** | 선언을 실제 행동으로 바꾸기 위해 어떤 메커니즘을 썼는가? (리더 행동, 제도 연결, 의례, 측정, 개정) | 내재화 메커니즘 맵 |
| **RQ4 결과** | 어떤 결과가 관찰되는가? — 특히 **위기·가치 충돌 상황에서 Creed가 실제 판단 기준으로 작동했는가?** | 결과 평가 매트릭스 |
| **RQ5 교훈** | 성공·실패를 가르는 조건은 무엇이며, 어떤 조건에서 일반화 가능한가? | 성공/실패 조건 명제 + 적용 경계 |

## 5. 분석 프레임워크

```
[도입 맥락]      [설계]          [내재화]            [시험(Test)]         [결과]
 동기·트리거  →  내용·구조   →   리더·제도·의례   →   위기·가치충돌 시   →  신뢰·성과·
 리더십 주체     작성 방식       측정·개정           실제 선택            지속성·부작용
       ↑_______________________ 피드백(개정·재정립) ________________________|
```

**핵심 분석 관점 — "Stress Test" 원칙**
Creed의 효과는 평시가 아니라 **가치와 단기 이익이 충돌하는 순간**에 드러난다. 따라서 각 사례에서 최소 1개 이상의 "결정적 사건(critical incident)"을 식별하고, 당시 선택이 Creed와 일치했는지·그 근거가 무엇인지 추적한다.

**분석 층위**
- L1 문서: 무엇이 쓰여 있는가 (텍스트 분석)
- L2 제도: 무엇에 연결되어 있는가 (HR·거버넌스·의사결정 절차)
- L3 행동: 실제로 어떻게 결정했는가 (결정적 사건)
- L4 인식: 구성원·외부가 어떻게 체감하는가 (설문·평판·리뷰 데이터)

> L1이 좋아도 L3에서 불일치하면 "선언형", L1~L4가 일관되면 "작동형"으로 분류한다.

## 7. 연구 방법

### 7.1 설계
- **다중 비교 사례연구** (Yin의 replication logic)
- 사례 내 분석: **과정추적(process tracing)** — 도입 → 내재화 → 결정적 사건 → 결과의 시간 순서 재구성
- 사례 간 분석: 성공·혼재·실패 사례의 조건 비교 (필요 시 crisp-set QCA로 조건 조합 탐색 — 사례 수 충분할 때만)

### 7.2 선택 편향 방지 원칙
- 성공 사례만 모으면 "Creed가 있으면 성공한다"는 **생존자 편향**에 빠진다.
- 따라서 **성공 / 혼재(성공 후 훼손) / 실패(선언과 행동 괴리)** 를 의도적으로 함께 선정한다.
- 같은 기업의 **시기별 변화**(예: 모범 사례로 평가받다가 이후 논란)를 별도 관찰 단위로 둔다.

### 7.3 사례 선정 기준
1. §3.2 Creed 판정 기준 충족
2. 도입 목적·시점을 1차 자료로 확인 가능
3. 결정적 사건이 최소 1개 이상 공개 기록으로 추적 가능
4. 산업·지역·소유구조(창업가/전문경영/가족기업) 다양성 확보

### 7.4 후보 사례 풀 (미확인 — Phase 1에서 판정·확정)

| 구분 | 후보 | 관찰 포인트(가설) |
|---|---|---|
| 원형(archetype) | Johnson & Johnson — *Our Credo* | 이해관계자 우선순위 명문화의 원형, 위기 대응 사례와 이후 제품 관련 논란의 대비 |
| 서비스 운영형 | Ritz-Carlton — *Credo* / Gold Standards | 일상 운영 의례(데일리 라인업 등)를 통한 내재화 |
| 턴어라운드형 | Kyocera Philosophy → JAL 재건 적용 | 파산 기업 재건에서 경영철학 이식 효과 |
| 제조 운영철학형 | Toyota — *Toyota Way* | 암묵지의 명문화, 글로벌 확산, 품질 위기 시 작동 여부 |
| 창업가 철학 계승형 | Hewlett-Packard — *HP Way* | 창업자 퇴장 후 계승·해체 과정 |
| 이해관계자·목적형 | Novo Nordisk Way / Merck / Patagonia 중 선정 | 목적·가치의 사업 의사결정 연결 방식 |
| 참여형 재정립 | IBM — 전사 온라인 참여를 통한 가치 재정립 | 하향식 vs. 참여형 작성 방식 비교 |
| 그룹 거버넌스형 | Tata Group — 가치·행동강령 체계 | 다계열사 그룹의 공통 철학 운영 |
| 원칙 운영형 | Amazon — Leadership Principles | 채용·평가 제도에 직결된 원칙 운영과 부작용 논쟁 |
| 문화 전환형 | Microsoft — 2014년 이후 문화 전환 | Creed 문서보다 리더 행동 중심 전환의 비교군 |
| 실패·괴리형 | Enron, Wells Fargo, Volkswagen 중 선정 | 선언 가치와 인센티브·통제 구조의 괴리 |

- 목표 사례 수: **핵심 심층 사례 6~8개 + 비교·반례 3~4개**
- 최종 확정은 판정 기준 적용 결과와 자료 가용성에 따라 조정

### 7.5 자료원과 근거 등급

| 등급 | 자료 | 용도 |
|---|---|---|
| A (1차 공식) | Creed 원문 및 개정 이력, 연차·지속가능경영보고서, 주주서한, 공식 사사(社史), 규제기관·법원 문서 | 사실 확정 |
| B (1차 증언) | 경영자 연설·인터뷰·자서전, 의회 청문회 기록 | 의도·동기 추정 |
| C (학술) | 동료심사 논문, 하버드·IMD 등 교육용 케이스 | 해석·이론 연결 |
| D (독립 보도·데이터) | 주요 언론 탐사보도, 직원 리뷰 데이터, 평판 조사 | 교차검증, L4 인식 |
| E (2차 요약) | 블로그·컨설팅 요약물 | 단서 탐색용 — 단독 근거로 사용하지 않음 |

- 결론을 좌우하는 사실은 **A등급 1개 또는 독립 B~D등급 2개 이상**으로 확인
- 기업 자체 발간물은 **"자기 서술"** 로 표시해 외부 자료와 구분

### 7.6 사례 코딩 항목 (Codebook 초안)

| 영역 | 코딩 변수 |
|---|---|
| 맥락 | 도입 연도, 트리거(창업/위기/M&A/확장/턴어라운드/스캔들), 주도 주체, 소유구조, 산업 |
| 설계 | 이해관계자 우선순위 유무·순서, 추상도(행동 지침 수준 vs. 원칙 수준), 분량, 작성 방식(하향/참여), 개정 주기 |
| 내재화 | CEO 반복 언급, 채용·평가·승진 연계, 교육·의례, 측정(설문), 위반 시 제재, 개정 절차 |
| 시험 | 결정적 사건 내용, 당시 선택, Creed와의 일치 여부, 근거 자료 |
| 결과 | 위기 후 신뢰 회복 속도, 구성원 체감(가능 시), 장기 지속성, 부작용(교조화·위선 인식·혁신 저해 등) |
| 근거 | 항목별 근거 등급·출처·확인일 |

## 8. 결과 해석의 한계와 대응

| 한계 | 설명 | 대응 |
|---|---|---|
| 인과 식별 불가 | Creed와 재무 성과의 인과를 사례연구로 증명할 수 없음 | "성과를 냈다" 대신 **"결정적 순간에 판단 기준으로 작동했는가"** 를 1차 결과 지표로 삼음 |
| 사후 신화화 | 성공 후 회고적으로 미화된 서사 | 사건 당시 동시대 자료 우선, 사후 회고와 분리 |
| 자기 서술 편향 | 기업 발간물의 긍정 편향 | 외부 자료로 교차검증, 표시 구분 |
| 생존자 편향 | 성공 사례 과대 대표 | 실패·혼재 사례 의도적 포함 |
| 시점 불일치 | 도입 시점과 결과 관찰 시점의 간극 | 사례별 타임라인 명시 |
